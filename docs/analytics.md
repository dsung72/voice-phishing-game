# GA4 집계 기준

2026-09-16부터 게임 내부 화면 이동은 `screen_view` 대신 `game_screen_view`로 기록합니다.
기존 코드에서는 웹페이지 접속에 더해 게임 내부 화면 이동도 화면 조회로 전송했습니다.
이번 변경은 방문 조회와 게임 내 활동을 구분하기 위한 것입니다.

| 확인할 내용 | 이벤트·지표 | 집계 기준 |
| --- | --- | --- |
| 페이지 조회 | `page_view` | 분석에 동의한 상태에서 페이지를 불러올 때 Google 태그가 전송합니다. 새로고침도 포함하며, 1인 1회나 1세션 1회를 의미하지 않습니다. |
| 게임 안의 화면 이동 | `game_screen_view` | 화면이 바뀔 때 전송합니다. 같은 화면을 연속 호출하면 중복 전송하지 않습니다. |
| 게임 시작 횟수 | `level_start` | 모드를 시작하거나 다시 플레이할 때 기록하는 기존 이벤트입니다. |
| 게임 완료 횟수 | `level_end` | 결과까지 진행했을 때 기록하는 기존 이벤트입니다. |
| 정답률 | `post_score` | 기존 점수 이벤트의 `score` 값입니다. |
| 답안 선택 | `scenario_answer` | 기존 문제별 정답·오답·시간초과 이벤트입니다. |
| 이용자 수 | GA4 사용자 지표 | 기기·브라우저 식별, 동의, 차단 여부 등의 영향을 받습니다. 시작 횟수나 행사 실제 체험 인원과 같지 않습니다. |

새 `game_screen_view` 이벤트의 화면 이름은 `screen_name`에 담깁니다.
화면 이름별로 탐색 보고서를 만들려면 GA4 관리 화면에서 이벤트 범위의 맞춤 측정기준으로
`screen_name`을 등록해야 할 수 있습니다. 이벤트 횟수 자체에는 등록이 필요하지 않습니다.

- 분석 동의 배너, 동의 저장 키, 측정 ID `G-95DKGBG9MY`를 유지합니다.
- 동의 전 활동을 나중에 소급 전송하지 않습니다.
- 이미 수집한 통계는 바뀌지 않습니다. 변경 전·후 조회수를 같은 기준으로 비교하지 마세요.
- 코드만으로 과거의 “조회수 138 / 활성 사용자 3”의 정확한 원인을 확정할 수 없습니다.
  해당 날짜의 `page_view`와 `screen_view` 이벤트 수, 사용 기기와 동의 상태를 함께 확인해야 합니다.
- 이 변경은 사이트의 전송 코드에 적용됩니다. GA4 관리 화면의 보고서·필터·맞춤 측정기준을 바꾸지는 않습니다.
